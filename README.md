# 2048 CUPCAKES

Play here: https://2048online.top/2048-CUPCAKES/

Welcome to the 2048 Cupcakes game! This is a fun and delicious variation of the classic 2048 game, where instead of numbers, you merge different types of cupcakes to reach the ultimate cupcake!

---

## How to Play

- **Objective**: Merge identical cupcakes to form higher-level cupcakes. Keep merging until you reach the final cupcake!
- **Controls**:
  - Use the **arrow keys** or **swipe gestures** (on touch-enabled devices) to move the cupcakes.
  - When two identical cupcakes collide, they merge into one higher-level cupcake.
  - Continue merging cupcakes until you create the highest possible cupcake!
- **Goal**: Try to reach the ultimate cupcake by combining smaller cupcakes in the grid.

## Features

- **Simple gameplay**: Easy to pick up and play, but hard to master.
- **Fun cupcake theme**: Different cupcakes as tiles make the game more visually appealing and delicious!
- **Responsive design**: Play on your desktop or mobile device.
- **Undo feature**: If you make a mistake, undo your last move.
- **Local high score tracking**: Keep track of your best performance.

## Installation

You can run the game locally by following these steps:

1. Clone the repository:

   ```bash
   git clone https://github.com/AshinTop/2048-CUPCAKES.git
   ```

2. Navigate to the project directory:

   ```bash
   cd 2048-cupcakes
   ```

3. Open the `index.html` file in your browser.

   ```bash
   open index.html
   ```

   Or simply double-click the `index.html` file in your file explorer.

## How It Works

- The game is implemented using **HTML**, **CSS**, and **JavaScript**.
- The grid is a 4x4 matrix, and the game logic is designed to handle merging cupcakes of the same type.
- A random new cupcake will appear after each move, and the game ends when no more valid moves are possible.
